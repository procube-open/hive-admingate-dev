# 接続機種パスワード変更機能

## 現在対応機種一覧

`roles/prov-tools/files/playbooks/connection` 配下のYAMLファイルが、パスワード変更に対応する機種です。
IDManagerのOS種別（`osType`）には、ファイル名から拡張子の `.yml` を除いた値を登録します。

| OS種別の値 | ファイル |
| --- | --- |
| `eos` | `eos.yml` |
| `fortimail` | `fortimail.yml` |
| `fortios` | `fortios.yml` |
| `ios` | `ios.yml` |
| `iosxr` | `iosxr.yml` |
| `junos` | `junos.yml` |
| `linux` | `linux.yml` |
| `windows` | `windows.yml` |

## 新規追加方法

1. `roles/prov-tools/files/playbooks/connection` に、対象機種のパスワード変更処理を記述したYAMLファイルを追加します。
2. 母環境で次のコマンドを実行し、provtoolsイメージをビルドしてサービスをデプロイします。

	```sh
	hive build-images -l idm3-provtools
	hive deploy-services -l idm3-provtools
	```

3. IDManagerの画面で、次の手順によりOS種別を登録します。
	1. ベース設定のクラス編集画面を開きます。
	2. 接続仕様（`connectionSpecification`）の編集アイコンをクリックします。
	3. OS種別（`osType`）の編集アイコンをクリックします。
	4. 列挙値に次の内容を入力します。
		- 値：追加したYAMLファイル名から拡張子の `.yml` を除いたもの
		- 表示名：任意の値
